# FabioTv: release

Questo repository contiene **solo gli APK firmati di FabioTv per Android e le relative note di versione**. Non c'è codice sorgente.

- Ogni release ha l'APK, il suo checksum SHA-256 e le note in italiano.
- L'app controlla qui, senza token, se esiste una versione più recente e propone l'aggiornamento.
- Gli APK non contengono credenziali né dati personali.
- Uso personale: FabioTv non è un servizio e non fornisce contenuti.
